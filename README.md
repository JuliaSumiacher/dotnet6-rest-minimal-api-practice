# .NET 6 REST & Minimal APIs — Practice Repository

Hands-on exercises and practical projects developed during a comprehensive Udemy course on **C#, .NET / .NET Core / .NET 6**, modern REST API architecture, cloud deployment on **Azure**, and CI/CD pipelines with **Azure DevOps**.

## Key Topics & Technologies Covered

- **Core Stack:** C#, .NET 6, .NET Core, Visual Studio
- **API Development:**
  - Controller-based RESTful APIs (routing, model binding, DTOs, data validation, status codes, dependency injection)
  - **Minimal APIs** in .NET 6 (lightweight endpoints, route groups, filters)
  - API documentation and interactive testing with **OpenAPI / Swagger**
- **Data Access:**
  - **Entity Framework Core (EF Core):** Code-First migrations, `DbContext` configuration, LINQ queries, and relational database persistence
- **Cloud & DevOps:**
  - Cloud hosting and configuration on **Microsoft Azure** (App Service, Azure SQL)
  - Version control, automated builds, and CI/CD workflows with **Azure DevOps**

## Prerequisites

- [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0)
- [Visual Studio 2022](https://visualstudio.microsoft.com/) (with the *ASP.NET and web development* workload) or Visual Studio Code
- SQL Server / LocalDB (or an Azure SQL instance)
